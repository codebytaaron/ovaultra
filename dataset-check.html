Cathra Dataset Check

Find copied and mislabeled images in a medical image dataset before you train or test a model. It runs in your browser, and nothing is uploaded.

Drop a dataset folder here Folder names become labels, for example Normal/ and Abnormal/. Add train/ and test/ folders to check for leaks.

Why this matters

If the same scan appears in both the training and test sets, a model can look more accurate than it really is. If the same scan is labeled two different ways, no model can get both right. While building Cathra, I found both problems in a public ovarian ultrasound dataset, so I made this check free for anyone.

How it works

Each image is shrunk to a tiny grayscale “fingerprint” (a perceptual hash). Images whose fingerprints are almost the same look almost the same, even if they were resized, re-saved, or slightly cropped. Exact copies are confirmed with a file checksum.

Similar-looking images aren’t always true copies. Review the matches before removing anything. Research use only.
